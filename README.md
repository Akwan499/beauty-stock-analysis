# beauty-stock-analysis

| 数据类型 | 来源 | 采集工具/方法 |
|---------|------|-------------|
| 股价数据 | 沪深交易所 | Python akshare 接口 |
| 百度指数 | 百度 | 浏览器抓包分析，解析JSON |
| 股吧舆情 | 东方财富 | 公开API接口 |
| 小红书笔记 | 小红书 | mediacrawler + Cookie模拟登录 |
| 知乎讨论 | 知乎 | mediacrawler + Cookie模拟登录 |

> ⚠️ 致谢：本项目使用了开源项目 [mediacrawler] (https://github.com/NanmiCoder/MediaCrawler)，在此向项目维护者表示感谢。

## 核心发现

1. **相关性分析**：上海家化百度指数与股价呈中等强度正相关（r=0.47，p<0.05）；珀莱雅相关性较弱（r=0.15，不显著）
2. **事件研究**：双11事件窗口内，珀莱雅累计异常收益（CAR）显著为正，大促营销对股价存在短期正向冲击
3. **情感分析**：小红书情感倾向与股价波动呈弱正相关（r=0.37），情绪是连接消费热度与资本市场的重要变量

## 环境配置
本项目需要自行配置安装依赖，详情可见开源项目 [mediacrawler]说明
本项目需自行配置社媒的Cookie。通过浏览器开发者工具获取Cookie，将Cookie填入 `config.yaml` 中对应的位置
