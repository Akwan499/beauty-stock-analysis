# beauty-stock-analysis

## 项目简介
本项目旨在检验品牌网络声量与资本市场表现之间的传导机制，研究对象为珀莱雅和上海家化两家A股上市美妆公司，研究窗口为2025年全年。

## 数据来源与采集方法

| 数据类型 | 来源  | 采集工具/方法 |
| 股价数据 | 沪深交易所 | Python akshare 接口 |
| 百度指数 | 百度 | 浏览器抓包分析，解析JSON |
| 股吧舆情 | 东方财富 | 公开API接口 |
| 小红书笔记 | 小红书 | **mediacrawler** + Cookie模拟登录 |
| 知乎讨论 | 知乎 | **mediacrawler** + Cookie模拟登录 |

致谢：本项目使用了开源项目 [mediacrawler]，在此向项目维护者表示感谢。
